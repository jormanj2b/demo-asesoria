# Ribera & Ochoa Asesores · demo de portafolio

Sitio corporativo de varias páginas para una asesoría: servicios con tarifas, equipo, plazos fiscales y formulario de contacto validado.

**Sitio en vivo:** https://jormanbravo.com/demo-asesoria/

Ribera & Ochoa Asesores es un negocio **ficticio**. Este repositorio es una pieza de portafolio de **Jorman Bravo · Desarrollo web** ([portafolio](https://jormanbravo.com/)), no el sitio de una empresa real. Las direcciones, personas, precios y testimonios son de ejemplo, y las fotos están generadas para la demo.

## Qué incluye

- HTML, CSS y JavaScript sin frameworks ni dependencias externas (carga rápida y fácil de mantener).
- Diseño pensado primero para el celular, accesible con teclado y lector de pantalla.
- SEO en la página: título y descripción, Open Graph, datos estructurados (JSON-LD), `sitemap.xml` y `robots.txt`.
- Fuentes e imágenes servidas desde el propio sitio (WebP en varios tamaños), sin rastreadores.
- Política de seguridad de contenido (CSP) y ningún dato enviado a terceros.

## Publicación

GitHub Pages desde la rama `main`. Para un cliente real se conecta su dominio, se cambian los datos de ejemplo y se añade el número de WhatsApp o el servicio de formularios que use el negocio.

## English version

`en/` is a native English version for US clients, adapted to the US market as **Rivera & Ochoa Tax & Accounting** (fictional, Denver, CO): IRS deadlines (1040-ES, W-2/1099-NEC, Tax Day), US plans in dollars (freelancers, LLCs and S corps, payroll, LLC formation), 10-digit phone validation, English form messages, cookie notice and legal pages. It reuses the root CSS, fonts and photos. Every page has an ES/EN switch in the top bar.

**Live:** https://jormanbravo.com/demo-asesoria/en/
